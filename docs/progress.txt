## 2026-08-28 — Blank Page Issue Resolved

### 🐛 Issue
User reported: "websitenya blank tidak memunculkan apa apa" (website is blank, doesn't show anything).

### 🔍 Root Cause
All page components and common components were using a global `route('xxx')` helper (Ziggy-style) that **does not exist** in this project. The project uses **Wayfinder** instead — Laravel's official type-safe route generator that produces imports from `@/routes/*` and `@/actions/*`.

Browser console showed:
```
ReferenceError: route is not defined
  at Login (http://[::1]:5174/resources/js/pages/Auth/Login.tsx:254:43)
```

This caused the entire React tree to fail to render, producing a blank page.

### 🛠️ Fix
Replaced all `route('xxx')` calls with Wayfinder imports from `@/routes`:

| File | Old | New |
|------|-----|-----|
| `resources/js/pages/Auth/Login.tsx` | `post(route('login'))`, `route('register')` | `post(login.url())`, `register.url()` |
| `resources/js/pages/Auth/Register.tsx` | `post(route('register'))`, `route('login')` | `post(register.url())`, `login.url()` |
| `resources/js/pages/Profile.tsx` | `patch(route('profile.update'))`, `put(route('profile.password'))` | `patch(update.url())`, `put(password.url())` |
| `resources/js/components/common/AppLayout.tsx` | `route('dashboard')` | `dashboard.url()` |
| `resources/js/components/common/Header.tsx` | `route('profile.edit')`, `route('logout')` | `profileEdit.url()`, `logout.url()` |
| `resources/js/components/common/YearToggle.tsx` | `route('session.set-year')` | `setYear.url()` |

### ✅ Result
- Login page renders successfully ("SIM Surat RSGM" title, Username/Password form, Masuk button)
- Login as `superadmin` / `password` redirects to `/dashboard`
- Dashboard renders with sidebar containing: Dashboard, Surat Masuk, Surat Keluar, Disposisi, IT Helpdesk, Lapor Kendala, Notifikasi, Rekap, Admin
- Header shows YearToggle, NotificationBell, user dropdown
