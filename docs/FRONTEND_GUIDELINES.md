# Frontend Guidelines (FRONTEND_GUIDELINES)
## SIM SURAT RSGM UNIMUS

**Versi:** 1.0
**Tanggal:** 2026-08-27
**Referensi:** PRD.md, APP_FLOW.md, TECH_STACK.md, AGENTS.md

---

## 1. Prinsip Dasar

1. **Functional components + hooks** — tidak ada class component.
2. **TypeScript strict** — selalu definisikan interface, tidak ada `any`.
3. **Tailwind only** — tidak ada inline styles, tidak ada CSS module terpisah.
4. **shadcn/ui sebagai base** — cek dulu sebelum bikin komponen baru.
5. **Inertia-first** — gunakan `useForm()`, `<Link>`, `usePage()`; hindari fetch manual.
6. **Mobile-first responsive** — desain dari layar kecil ke besar.
7. **Reusable components** — letakkan di `components/common/`, bukan duplikasi di halaman.
8. **Bahasa Indonesia** untuk semua UI text.

---

## 2. Tech Stack Frontend (Recap)

- **React 18** + **TypeScript 5** + **Inertia.js 2** + **Vite 5**
- **Tailwind CSS 3** + **shadcn/ui** (copy-paste components)
- **Bun** sebagai package manager
- **Tiptap** untuk rich text editor
- **Sonner** untuk toast notifications
- **date-fns** untuk date formatting
- **Lucide React** untuk icons

### 6.2 Form Component (with useForm)

```tsx
// resources/js/components/surat/SuratMasukForm.tsx
import { useForm } from '@inertiajs/react';
import { Form } from '@/components/ui/form';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { Textarea } from '@/components/ui/textarea';
import { Select } from '@/components/ui/select';
import { Button } from '@/components/ui/button';
import { FileUpload } from '@/components/common/FileUpload';
import { SuratMasukFormData } from '@/types/surat';

interface Props {
  indeksOptions: Array<{ id: number; kode: string; nama: string }>;
  initialData?: Partial<SuratMasukFormData>;
  submitUrl: string;
  method?: 'post' | 'put';
}

export function SuratMasukForm({ indeksOptions, initialData, submitUrl, method = 'post' }: Props) {
  const { data, setData, post, put, processing, errors, reset } = useForm<SuratMasukFormData>({
    tanggal_terima: initialData?.tanggal_terima ?? new Date().toISOString().split('T')[0],
    tanggal_surat: initialData?.tanggal_surat ?? '',
    nomor_surat: initialData?.nomor_surat ?? '',
    pengirim: initialData?.pengirim ?? '',
    perihal: initialData?.perihal ?? '',
    keterangan: initialData?.keterangan ?? '',
    indeks_id: initialData?.indeks_id ?? null,
    file: null as File | null,
  });

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (method === 'post') {
      post(submitUrl, { forceFormData: true });
    } else {
      put(submitUrl, { forceFormData: true });
    }
  };

  return (
    <Form onSubmit={handleSubmit} className="space-y-4">
      <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
        <div>
          <Label htmlFor="tanggal_terima">Tanggal Terima *</Label>
          <Input
            id="tanggal_terima"
            type="date"
            value={data.tanggal_terima}
            onChange={(e) => setData('tanggal_terima', e.target.value)}
            error={errors.tanggal_terima}
            required
          />
        </div>
        <div>
          <Label htmlFor="tanggal_surat">Tanggal Surat *</Label>
          <Input
            id="tanggal_surat"
            type="date"
            value={data.tanggal_surat}
            onChange={(e) => setData('tanggal_surat', e.target.value)}
            error={errors.tanggal_surat}
            required
          />
        </div>
      </div>

      <div>
        <Label htmlFor="nomor_surat">Nomor Surat *</Label>
        <Input
          id="nomor_surat"
          value={data.nomor_surat}
          onChange={(e) => setData('nomor_surat', e.target.value)}
          error={errors.nomor_surat}
          required
        />
      </div>

      <div>
        <Label htmlFor="pengirim">Pengirim *</Label>
        <Input
          id="pengirim"
          value={data.pengirim}
          onChange={(e) => setData('pengirim', e.target.value)}
          error={errors.pengirim}
          required
        />
      </div>

      <div>
        <Label htmlFor="perihal">Perihal *</Label>
        <Input
          id="perihal"
          value={data.perihal}
          onChange={(e) => setData('perihal', e.target.value)}
          error={errors.perihal}
          required
        />
      </div>

      <div>
        <Label htmlFor="keterangan">Keterangan</Label>
        <Textarea
          id="keterangan"
          value={data.keterangan}
          onChange={(e) => setData('keterangan', e.target.value)}
          error={errors.keterangan}
          rows={3}
        />
      </div>

      <div>
        <Label htmlFor="indeks_id">Indeks</Label>
        <Select
          value={data.indeks_id?.toString() ?? ''}
          onValueChange={(v) => setData('indeks_id', v ? Number(v) : null)}
          options={[
            { value: '', label: '-- Pilih Indeks --' },
            ...indeksOptions.map((i) => ({ value: i.id.toString(), label: `${i.kode} - ${i.nama}` })),
          ]}
        />
      </div>

      <div>
        <Label htmlFor="file">File Surat (PDF/JPG/PNG, max 10MB) *</Label>
        <FileUpload
          accept=".pdf,.jpg,.jpeg,.png"
          maxSize={10 * 1024 * 1024}
          onChange={(file) => setData('file', file)}
          error={errors.file}
        />
      </div>

      <div className="flex gap-2 justify-end">
        <Button type="button" variant="outline" onClick={() => window.history.back()}>
          Kembali
        </Button>
        <Button type="submit" disabled={processing}>
          {processing ? 'Menyimpan...' : 'Simpan'}
        </Button>
      </div>
    </Form>
  );
}
```

### 6.3 DataTable (Reusable)

```tsx
// resources/js/components/common/DataTable.tsx
import { Link, router } from '@inertiajs/react';
import { Button } from '@/components/ui/button';
import { Pagination } from '@/components/ui/pagination';
import { useDebounce } from '@/hooks/useDebounce';
import { useEffect, useState } from 'react';

export interface Column<T> {
  key: keyof T | string;
  label: string;
  format?: 'date' | 'datetime' | 'currency' | 'truncate';
  width?: string;
  render?: (row: T) => React.ReactNode;
  sortable?: boolean;
}

interface Props<T> {
  data: T[];
  columns: Column<T>[];
  pagination?: {
    current_page: number;
    last_page: number;
    total: number;
    per_page: number;
  };
  filters?: Record<string, string | undefined>;
  searchPlaceholder?: string;
  actions?: (row: T) => React.ReactNode;
}

export function DataTable<T extends { id: number | string }>({
  data,
  columns,
  pagination,
  filters: initialFilters = {},
  searchPlaceholder = 'Cari...',
  actions,
}: Props<T>) {
  const [search, setSearch] = useState(initialFilters.search ?? '');
  const debouncedSearch = useDebounce(search, 300);

  useEffect(() => {
    if (debouncedSearch !== initialFilters.search) {
      router.get(
        window.location.pathname,
        { ...initialFilters, search: debouncedSearch, page: 1 },
        { preserveState: true, replace: true }
      );
    }
  }, [debouncedSearch]);

  return (
    <div className="space-y-4">
      <div className="flex items-center gap-2">
        <input
          type="search"
          placeholder={searchPlaceholder}
          value={search}
          onChange={(e) => setSearch(e.target.value)}
          className="border border-border rounded-md px-3 py-2 text-sm w-full md:w-80"
        />
      </div>

      <div className="border border-border rounded-lg overflow-hidden">
        <div className="overflow-x-auto">
          <table className="w-full text-sm">
            <thead className="bg-muted">
              <tr>
                {columns.map((col) => (
                  <th key={col.key.toString()} className="text-left p-3 font-medium" style={col.width ? { width: col.width } : undefined}>
                    {col.label}
                  </th>
                ))}
                {actions && <th className="text-left p-3 font-medium">Aksi</th>}
              </tr>
            </thead>
            <tbody>
              {data.length === 0 ? (
                <tr>
                  <td colSpan={columns.length + (actions ? 1 : 0)} className="p-8 text-center text-muted-foreground">
                    Tidak ada data.
                  </td>
                </tr>
              ) : (
                data.map((row) => (
                  <tr key={row.id} className="border-t border-border hover:bg-muted/50">
                    {columns.map((col) => (
                      <td key={col.key.toString()} className="p-3">
                        {col.render ? col.render(row) : formatCell(row[col.key as keyof T], col.format)}
                      </td>
                    ))}
                    {actions && <td className="p-3">{actions(row)}</td>}
                  </tr>
                ))
              )}
            </tbody>
          </table>
        </div>
      </div>

      {pagination && pagination.last_page > 1 && (
        <Pagination
          currentPage={pagination.current_page}
          lastPage={pagination.last_page}
          total={pagination.total}
        />
      )}
    </div>
  );
}

function formatCell(value: unknown, format?: string): string {
  if (value == null) return '-';
  if (format === 'date' && typeof value === 'string') {
    return new Date(value).toLocaleDateString('id-ID', { day: '2-digit', month: 'short', year: 'numeric' });
  }
  if (format === 'datetime' && typeof value === 'string') {
    return new Date(value).toLocaleString('id-ID');
  }
  if (format === 'truncate' && typeof value === 'string') {
    return value.length > 50 ? value.substring(0, 50) + '...' : value;
  }
  return String(value);
}
```

```ts
// useDebounce
export function useDebounce<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const timer = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(timer);
  }, [value, delay]);
  return debounced;
}
```

## 11. Accessibility (A11y)

- **Labels:** Setiap input harus ada `<Label htmlFor="...">`.
- **Alt text:** Image harus ada `alt` attribute.
- **Focus visible:** Outline biru saat focus (default browser, jangan override).
- **Keyboard navigation:** Tab order harus logis, Enter submit form, Esc close dialog.
- **Color contrast:** Ratio minimal 4.5:1 untuk body text.
- **ARIA:** Pakai `aria-label` untuk icon button, `aria-live="polite"` untuk toast.
- **Skip link:** "Skip to main content" di top of page.

---

## 12. Performance Best Practices

- **Code splitting:** Lazy load halaman besar dengan `lazy()`.
  ```tsx
  const Dashboard = lazy(() => import('@/pages/Dashboard'));
  ```
- **Memoization:** Pakai `useMemo` untuk computed values yang berat, `useCallback` untuk handler yang di-pass ke child.
- **Debounce search:** `useDebounce(value, 300)`.
- **Image optimization:** Pakai `<img loading="lazy">` untuk gambar di bawah fold.
- **Virtualization:** Untuk tabel > 100 rows, pakai `react-virtual` (opsional fase 2).

### 13.4 Polling (untuk notifikasi)
```tsx
import { router } from '@inertiajs/react';

export function useNotificationPolling(intervalMs = 30000) {
  useEffect(() => {
    const timer = setInterval(() => {
      router.reload({ only: ['unreadNotifications'] });
    }, intervalMs);
    return () => clearInterval(timer);
  }, [intervalMs]);
}
```

## 14. TypeScript Conventions

### 14.1 Interface Naming
- **Domain types:** PascalCase singular (`SuratMasuk`, `User`, `Disposisi`).

```ts
// ❌ Jangan
const handleChange = (value: any) => { ... };

const handleChange = (value: string | number) => { ... };
```

## 17. Penutup & Referensi Cepat

### 17.1 Cheat Sheet Harian

**Import yang sering dipakai:**
```tsx
import { Head, Link, useForm, usePage, router } from '@inertiajs/react';
import AppLayout from '@/components/common/AppLayout';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { Select } from '@/components/ui/select';
import { Textarea } from '@/components/ui/textarea';

import { toast } from 'sonner';
import { cn } from '@/lib/utils';
import { Loader2, Plus, Edit, Trash2, Eye } from 'lucide-react';
```

**snippets:**
- Form: `useForm<FormData>()` + `post(url)` + `processing` + `errors`.
- Table: `<DataTable data={...} columns={...} pagination={...} />`.
- Confirm: `<ConfirmDialog onConfirm={...} />`.
- Toast: `toast.success('Berhasil')` / `toast.error('Gagal')`.

### 17.2 Yang **TIDAK** Boleh Dilakukan

- ❌ Pakai `any` type.
- ❌ Inline style (`style={{ ... }}`).
- ❌ Fetch manual pakai `axios` / `fetch` (pakai Inertia).
- ❌ Pakai class component.
- ❌ Pakai Redux/Zustand untuk state sederhana.
- ❌ Hardcode route string (pakai Wayfinder).
- ❌ Hardcode URL file storage (pakai helper).
- ❌ Tampilkan pesan error mentah Laravel (mapping ke bahasa Indonesia).
- ❌ Skip loading state pada button submit.
- ❌ Skip empty state pada list/table.

### 17.3 Yang **HARUS** Dilakukan

- ✅ Definisikan interface untuk semua props dan data.
- ✅ Cek shadcn/ui dulu sebelum bikin komponen baru.
- ✅ Pakai `<Link>` untuk navigasi internal, `<a>` untuk eksternal.
- ✅ Pakai `useForm()` untuk form dengan file upload atau validation.
- ✅ Tampilkan loading state pada async actions.
- ✅ Tampilkan empty state dengan CTA yang jelas.
- ✅ Test di mobile viewport (DevTools responsive mode).
- ✅ Run `bun run lint` sebelum commit.
